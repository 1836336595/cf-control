# 负载观测的采样保护、控制准入与诊断

本说明对应 `PayloadStateObserver`、`ctbr_payload_state.py` 和机群控制入口。
观测器只消费 NOKOV 的位置、姿态和源时间戳；消息原始速度、加速度保留作诊断。
正常接受的位姿继续采用原始几何中心位置和原始旋转矩阵，避免另加一层位姿滤波滞后；
速度、加速度和机体系角速度来自观测器。

## 修改依据与证据范围

2026-10-23 的悬停日志在姿态参考已静止时仍记录到负载角速度尖峰，个别分量达到原来的
±8 rad/s 限幅。角速度会进入负载姿态 PD，而原先的反馈质量门控主要冻结慢构型补偿，
没有阻止这些限幅导数进入核心控制。旧 CSV 没有记录每次源采样间隔和观测创新，
因此不能断言尖峰一定由短采样间隔引起。

原实现存在三个可独立复现的问题：短间隔会放大导数修正；重复/倒序时间戳会重置历史；
越界导数经限幅后仍被当作有效反馈。还存在异步诊断问题：计算力矩所用的状态可能与
同一行 CSV 中后来读取的状态不同。本次针对这些问题增加回归和故障路径保护，
不把仿真通过解释为真实扰动或传感器模型已经辨识准确。

## 采样与接受规则

| 配置 | 当前值 | 含义 |
|---|---:|---|
| `observer_min_dt_s` | 0.005 s | 距上次接受样本过短时累积真实时间，不更新接受历史 |
| `observer_nominal_dt_s` | 0.010 s | 原增益对应的名义采样间隔 |
| `observer_max_dt` | 0.050 s | 单调源时间确有长间断时重新预热 |
| `observer_position_innovation_margin_m` | 0.020 m | 位置创新的额外容差；另加物理速度/加速度允许范围 |
| `observer_attitude_innovation_margin_deg` | 5° | 姿态创新额外容差；另加角速度允许范围 |
| `observer_min_samples` | 3 | 新初始化/长间断后至少需要的接受样本数 |

时间戳重复或倒序时拒绝整帧，既不回退已接受时间，也不重置历史。
时间不足时返回 `pending_interval`；这不是一个新的零速度样本。
源时间间断按相邻单调原始时间戳判断，不能因为连续拒绝造成“距上次接受很久”，
就自动重新初始化并接纳坏帧。

预测沿用原平动和 SO(3) 方程。设实际距上次接受的间隔为 Δt，
名义间隔为 Δt₀，令 s=min(1,Δt/Δt₀)。平动修正使用：

$$
\hat x^+=\hat x^-+\alpha s r_x,\quad
\hat v^+=\hat v^-+\beta s^2 r_x/\Delta t,\quad
\hat a^+=\hat a+\gamma s^3 r_x/\Delta t^2.
$$

姿态旋转修正使用 α_R s，角速度修正使用 β_R s²/Δt。
因此在正常 100 Hz 下保留原数值响应，短间隔不再按原固定增益放大噪声。
这是一项局部采样保护，不是任意采样时序下的稳定性证明。

创新门限按当前相邻源间隔计算，拒绝帧不会逐步放宽自己的门限。
位置/姿态创新异常，或者候选速度、加速度、角速度任一分量达到配置边界时，
整帧不提交；保留上一接受位姿和导数。不会把剪裁到边界的数值当成健康状态。
长间断重新预热时，也不能立即以零导数放行控制或触地释放。

## 控制与异常退出

`_payload_state_ready(state, now)` 验证控制使用的同一份状态：消息有效、导数已预热、
观测更新确实接受、质量合格、接收时间和已知源时间新鲜。拒绝、等待间隔和初始化状态
不能进入新的负载核心计算，也不能触发负载接地后释放支撑。

短异常期间沿用最后一组完整运输输出，不只保留姿态 PD 的某一项。
运输位置 I、差分力积分和构型补偿的新学习暂停；已有有界构型平滑段按原策略处理。
正常数据恢复后重新计算；持续失效则在 `mocap_hold_s` 预算耗尽后进入已有受控下降，
保留当时的竖直支撑残差，避免缓存失效时切到普通悬停参考。
当前运输缓存预算为 0.20 s；预抬失效确认仍采用 `emergency_land_after_s: 0.50`。
运输没有第二层观测保持预算，也不在空中把该故障改成全机零推力中止。

### 预抬期间的短采样等待

`pending_interval` 表示距上次接受样本不足 5 ms，观测器正在累积时间，
与异常位姿、导数越界和初始化不同。2026-10-23 的预抬日志曾在 60 s 内出现
321 次从上升切换到暂停，导致参考速度反复归零、稳定确认反复重置。
负载最终抬到 0.256 m，但刚开始保持就触发了 60 s 超时。

现在仅预抬轨迹在该等待状态下可短暂使用最近质量合格的完整状态。
允许年龄取 `observer_max_dt`、飞机 `state_timeout` 和 50 ms 的最小值，
同时检查原接收时间和原源时间；pending 不刷新这些时间。
只有同一接受历史、没有期间拒绝、当前源有效时才可复用；
真正拒绝、长间断重新预热或缓存过期继续暂停。

这允许预抬保持速度、加速度和已存在的稳定确认时钟。
期间保留已建立的竖直积分支撑，冻结新的 Z 积分更新，避免退回普通积分上限。
pending 本身不能启动或完成接管确认；最终接管仍需要新接受的有效样本。
绳长校准、负载核心、慢构型学习和接地释放继续使用严格的反馈准入。
`prelift_timeout_s` 保持 60 s，间隙和竖直速度门槛也不因此放宽。

## CSV 如何查看

原有 `payload_position_*`、姿态、速度、加速度和角速度列来自生成该组运输输出时的
完整状态快照，三架飞机共用相同源快照。缓存输出仍保留原计算时间和原状态。
新列全部追加，旧列前缀顺序不变。

| 字段 | 查看内容 |
|---|---|
| `payload_control_time_s` / `payload_control_age_s` | 力命令计算时刻，以及到当前发布的年龄 |
| `payload_control_sample_time_s` | 该组控制所用已接受源时间戳 |
| `payload_control_reused` | 是否正在复用旧运输输出 |
| `payload_observer_*` | 该组控制输入对应的观测状态、间隔、创新和计数 |
| `payload_source_stamp_s` / `payload_source_received_age_s` | 最新收到的源帧时间与接收年龄 |
| `payload_source_raw_position_*` / `payload_source_raw_*_rad` | 最新源帧的中心位置与姿态 |
| `payload_source_observer_*` | 最新帧为何接受、等待或拒绝；不能拿它替换控制输入 |
| `payload_prelift_feedback_reused` / `payload_prelift_feedback_age_s` | 预抬是否因短采样等待复用了可信状态、其原接收年龄 |
| `prelift_vertical_integral_learning` | 是否允许预抬 Z 积分更新；复用期间为 0，但已有支撑仍保留 |

`*_input_dt_s` 是相邻单调源间隔，`*_update_dt_s` 是距上次接受样本的间隔。
创新位置单位为 m，姿态创新为旋转向量、单位 rad；状态的 `*_clipped` 标记表示
候选导数触界而被拒绝，不表示已发送一个剪裁后的健康导数。
初始化时没有间隔的字段为 NaN。

常见状态：`initializing`、`updated`、`gap_reset`、`pending_interval`、
`nonmonotonic_time`、`invalid_input`、`position_innovation`、
`attitude_innovation`、`derivative_limit`。

## 与积分速度权重的关系

观测器修复针对负载位姿导数；`transport_position_pid_integral_velocity_weight`
针对各飞机 native 位置 I 的速度误差输入，二者不是同一条反馈。
修改该权重不改变位置控制 D 项，不能把权重置零理解为移除了速度阻尼。
当前保持 1.0，避免在验证观测修复时同时更改原实飞积分行为。

离线对照脚本和产物位于 `scripts/ctbr_logs/observer_fix_20261023/`。
对照覆盖权重 1、0.5、0 的完整 100 s 接管窗口与降落，并额外比较记录中平均速度
差异的静态注入。该注入是压力测试，不是完整的固件 EKF 误差模型；
不能只凭简化仿真否定此前权重 0 实飞较差的观察。
