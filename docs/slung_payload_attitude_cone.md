# 固定质心的负载圆锥姿态轨迹

此模式保持负载几何中心的目标位置不动，让负载自身 +Z 轴与世界 +Z 轴保持配置的夹角，
倾斜方向围绕世界 +Z 轴按配置圈数扫描。当前启用的轨迹是 `circle`；切换到本模式时，
圆锥参数已设为 15°、两圈、每圈 30 s。它是姿态轨迹，不是让负载中心绕圆。
当前模型将几何中心视为质心；实际质心偏移没有单独标定。

## 配置

实飞与回放共用 `config/slung_payload.yaml` 中的任务参考：

```yaml
slung_payload:
  target_payload_height_m: 0.60
  trajectory:
    mode: attitude_cone
    center_xy: [0.0, 0.0]
    cone_half_angle_deg: 15.0
    cone_period_s: 30.0
    cone_transition_s: 5.0
    revolutions: 2.0
    direction: ccw
    settle_s: 3.0
  flight_validation_transport_s: 100.0
```

| 参数 | 含义 |
|---|---|
| `center_xy` | 固定质心的世界 XY；省略时沿用原悬停目标 XY，不填写 `null` |
| `target_payload_height_m` | 固定质心目标高度，当前 0.6 m |
| `cone_half_angle_deg` | 扫描阶段自身 +Z 与世界 +Z 的夹角，当前切换配置为 15° |
| `cone_period_s` | 每圈独立扫描的总时间，含该圈相位平滑起停，当前 30 s |
| `cone_transition_s` | 扫描前倾斜与扫描后恢复水平，各自 5 s |
| `revolutions` | 完整扫描圈数，正整数，当前配置为 2；总扫描时间为圈数乘周期 |
| `direction` | `ccw` 为从上向下看逆时针；`cw` 为顺时针 |

`radius_m`、`speed_mps` 是单圆/八字的参数，不决定锥角或姿态扫描速度。
普通飞机任务仍保持 `ctbr_trajectory.trajectory_mode: hover`。
仿真物理和传感器参数继续在独立 `config/slung_simulation.yaml`，当前离线观察窗口为 100 s。
本模式没有修改独立起飞、运输增益或机载 Mellinger 模型。

## 时间和姿态约定

进入 `TAUT_RAMP` 为 h0，按上述圆锥配置切换后的时间如下：

| 时间 | 参考 |
|---|---|
| h0–17 | 原张力建立、调平与抬升参考 |
| h17–20 | 额外保持 |
| h20–25 | 质心保持在 `[0,0,0.6]`，平滑倾斜至 15° |
| h25–55 | 保持 15° 锥角，倾斜方向扫第一圈 |
| h55–85 | 保持 15° 锥角，以相同相位参考扫第二圈 |
| h85–90 | 平滑恢复水平 |
| h90–100 | 原位置水平保持 |
| h100 起 | 原协同降落与停推流程 |

扫描角速度并非常数，每圈分别使用相同的五次相位平滑起停，一圈总时间为 30 s。
每圈末尾角速度与角加速度归零，下一圈从同一姿态重新起步；圈边界保持 15° 倾斜，不先回水平。
因此两圈的期望姿态、角速度和角加速度随各自圈内时间相同，便于逐圈比较跟踪结果。
倾斜、各圈扫描和恢复阶段之间的角速度与角加速度连续。
锥角参考在整个扫描阶段保持配置的 15°；进入和退出阶段按参考平滑变化。

每增加一圈，扫描时长增加一个 `cone_period_s`，默认增加 30 s；进出时间仍各为 5 s。
当前两圈姿态参考总长 70 s，在接管后 h90 完成。三圈时参考在 h120 完成，须手动将
`flight_validation_transport_s` 与 `ctbr_trajectory.hover_duration_s` 都设为至少 120 s，
并按实验需要再留水平保持裕量；离线 `slung_simulation.post_handoff_s` 也需同步延长。
初始化仍检查两个任务窗口是否覆盖完整参考，超出时拒绝运行，不会自动延长窗口。

仅指定 +Z 轴的方向不能唯一确定完整姿态，因此实现选取一条起止闭合的旋转参考。
每扫描完整一圈，负载都回到该圈开始的倾斜姿态；全部圈数完成后才恢复水平。
没有额外指定整机 yaw 转满一圈。
Euler roll、pitch、yaw 会随该姿态产生耦合变化，不能只检查某一个 Euler 角是否恒定。
精确旋转矩阵和角速度定义见 [公式说明](slung_controller_formulas.md)。

## 飞机参考与前馈

负载倾斜会改变挂点位置和重力下的静态张力分配。直接固定原水平绳向，或者将整个三机构型
一起倾斜，都可能使目标构型与负载力矩不一致。

本模式按每个期望姿态重新生成名义重力平衡绳向，并解析计算绳向速度和加速度。
三机参考由固定负载中心、旋转挂点、冻结的参考绳距和平衡绳向共同生成。
参考保留每根冻结绳距，三机实际位置仍需各自控制器跟踪。

期望负载角速度、角加速度进入负载力矩前馈和挂点惯性补偿；完整飞机构型加速度补偿保留
原有向心项去重。平衡参考使用名义重力和零静态力矩，实际控制分配仍包含位置/姿态反馈和
动态力矩，不把参考分配当成测量张力。

`transport_attitude_trim_dynamic_enabled: false` 是默认静态策略：慢姿态 trim 在倾斜、扫描、恢复期间冻结学习，保留之前的小幅世界系参考偏置。
显式设为 `true` 且总开关 `transport_attitude_trim_enabled: true` 时，改用瞬时完整圆锥目标姿态计算误差，
可在健康的动态参考期间继续学习。新偏置直接累计在世界系，既有端点不会随锥轴方向重转；
偏置及其完整速度、加速度在名义三机参考之后叠加。
同时开启 `transport_attitude_trim_during_lift_enabled` 时，张力渐增结束且协同混合达到1后
即可在抬升/调平参考内更新，当前最早h5；关闭时沿用h17后才更新。前5秒仍保持原接管过程，
其余反馈健康和限幅门控不变；这不等于实际负载已经调平或自动延长任务窗口。
两种模式均保留原每机 10 mm 偏置、1.5 mm/s 速度和 2 mm/s² 加速度预算；动态偏置零和，1 s 段间为 C2，冻结时完成当前段再保持。

动态 trim 另检查角速度范数、相邻源位姿步长和异常后的恢复时间，参数与 CSV 字段见
[README 的补偿说明](../README.md#姿态构型补偿) 和 [公式说明第 9 节](slung_controller_formulas.md#9-姿态到构型的慢修正与下降衔接)。
这些质量门控只暂停新 trim 更新，不改负载核心环和观测器；差分积分仍在运动期间冻结，native 位置 PID 继续沿用原健康门控。
动态模式的三维 `integral` 是世界系小角累计诊断，不能重建不同目标姿态下积累的世界偏置，执行值需看每机 PVA 字段。
运动滞后可能被慢积分学习，因而这里只保证学习偏置有界和参考连续，不能据此保证闭环收敛或不振荡。

中途退出先从当时完整姿态和角速度平滑制动，
再恢复水平；实测平动 PVA 先连续制动，在停住的位置保持到调平结束，再下降。
姿态恢复期间继续按重力平衡绳向生成三机参考，并检查箱体最低角的参考离地间隙。
初始条件无法满足连续制动与间隙约束时，使用已有的支撑保持/重规划路径。
轨迹正常完成且参考已水平静止时直接沿原下降规划执行，不增加调平等待。

## 仿真和可视化

先按上节把 `trajectory.mode` 切换为 `attitude_cone`，再在原 udaan 环境、本仓库 scripts 目录执行：

```bash
python simulate_slung_handoff.py --output ctbr_logs/attitude_cone_check
python plot_slung_circle_trace.py ctbr_logs/attitude_cone_check/simulation_trace.csv
```

脚本名称保留兼容，但会自动显示圆锥姿态图：自身 +Z 端点在水平面的投影、实际/期望锥角、
轴方向误差、质心位置和 RPY。保存静态图：

```bash
python plot_slung_circle_trace.py ctbr_logs/attitude_cone_check/simulation_trace.csv \
  --save ctbr_logs/attitude_cone_check/payload_cone.png --no-show
```

质心参考固定不等于实际质心完全不动，应检查位置误差。
轴端点投影是方向余弦，不是以米为单位的负载运行轨迹。
实飞 CTBR CSV 和模拟 trace 均增加 `payload_body_z_*`、`payload_target_body_z_*`、
`payload_cone_half_angle_deg`、`payload_target_cone_half_angle_deg`、`payload_cone_axis_error_deg`。
模拟 summary 另统计扫描期间的质心误差、全姿态误差、+Z 方向误差和相对配置锥角的误差。
比较动态补偿时应固定轨迹、物理几何、机体设置、延迟与噪声，对照关闭、静态和动态模式，
逐圈检查姿态误差、偏置趋势与限幅，并覆盖源位姿异常和扫描中途降落。名义模型中的改善不等同于实飞机体差异已被补偿。

切换回其他任务时只修改 `trajectory.mode` 为 `hover`、`circle` 或 `figure_eight`；
`center_xy` 在三个移动/姿态模式中的含义不同，应对照各模式说明。

## 2026-10-23 历史 10° 两圈离线验证

以下结果对应历史 10°、静态 trim 配置，不代表当前 15° 配置或新增动态补偿的验证。
`revolutions: 2.0`、每圈 30 s 的完整 100 s 接管任务已通过 Udaan/MuJoCo 回放，
完成两圈、恢复水平、计划下降和三机停推。两圈各有 2100 个扫描控制时刻，
质心参考均保持 `[0,0,0.6]`，目标锥角均为 10°。

| 指标 | 第一圈 | 第二圈 |
|---|---|---|
| 质心位置误差 RMS | 4.87 mm | 5.15 mm |
| +Z 方向误差 RMS | 1.331° | 1.457° |

最小机间距约 0.491 m，主机角速度指令饱和占比为 0。
本地结果为 `ctbr_logs/attitude_cone_2cycles_20261023/verified`，逐圈独立核验见
`per_cycle_verification.json`。166 项轨迹、衔接、日志和参数相关测试通过，系统 Python 3.8
验证了各圈相位边界。增加圈数并不保证后一圈误差更小，也没有修复最近实飞中发现的
观测导数尖峰、未收敛启动或实际循环掉频问题。

## 2026-10-23 历史单圈离线验证

以下结果对应 10°、`revolutions: 1.0` 的历史配置，不代表当前 15° 两圈配置或新增动态补偿的验证。
当时使用 Udaan/MuJoCo、机载 Mellinger、电机物理和 70 Hz 主机控制链，分别运行默认延迟
和较大延迟的完整 100 s 接管任务，均完成圆锥扫描、计划下降、负载接地和三机停推。
位置/姿态指标仅统计中间 30 s 扫描阶段，每组 2100 个控制时刻；进入、退出和降落不混入该指标。

| 指标 | 默认：位姿 10 ms、命令 5 ms | 位姿 20 ms、命令 10 ms |
|---|---|---|
| 质心位置误差 RMS | 4.87 mm | 4.97 mm |
| 自身 +Z 方向误差 RMS | 1.331° | 1.337° |
| 相对 10° 的锥角误差 RMS | 1.003° | 0.995° |
| 实际平均锥角 | 9.252° | 9.262° |
| 最小机间距 | 0.491 m | 0.491 m |
| 主机角速度指令饱和占比 | 0 | 0 |

参考质心严格固定在 `[0,0,0.6]`，参考锥角为 10°；实际轨迹仍有欠跟踪。
默认实际锥角范围约 7.96°–10.05°，不能将仿真完成解读为实际质心严格不动或锥角严格恒定。
两组仿真均使用当时的任务增益，没有为了此轨迹调大负载姿态带宽或改写实飞机载参数。

本地输出目录为 `ctbr_logs/attitude_cone_20261023/verified` 与 `delay_check`；各自包含
`simulation_trace.csv`、`summary.json`、`input_parameters.yaml` 和独立数值核验 JSON。
默认结果图为 `verified/payload_cone.png`。运行数据由 Git 忽略，文档不依赖提交这些文件。

额外测试覆盖完整旋转、角速度/角加速度、平衡绳向/三机 PVA 导数、实飞日志字段，以及
中途退出的连续衔接、低高度箱体间隙、静态力矩平衡和不可行规划的保持/重试。
系统 Python 3.8 导入和离线 ROS 参数 XML-RPC 检查已通过；没有启动实飞节点或连接无线电。
