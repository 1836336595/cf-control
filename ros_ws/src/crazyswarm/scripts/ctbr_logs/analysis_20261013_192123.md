# 最新 CSV 分析与本次修复

源文件：`multi_ctbr_20261013_192123.csv`。

## CSV 证据

- 阶段为 `TAKEUP` 后进入 `emergency_landing`，负载没有进入协同运输。
- 三架机预抬参考最终 `payload_prelift_reference_lead_m` 达到约 `1.6 m`；`payload_ground_clearance_m` 仍约 `0.008 m`，随后触发 `payload_prelift_failure_reason=max_lead`。
- XY 位置误差峰值：CF3 约 `0.24 m`，CF4 约 `0.24 m`，CF5 约 `0.23 m`。误差方向和三架机排列一致，表现为绳索变紧后飞机向负载中心靠拢。
- 预抬期间 `desired_force_x/y` 通常只有约 `0.03–0.05 N`，而垂直推力上升到约 `0.7 N`；原独立 PID 的 XY 修正不足以抵消绳索水平分量。

## 修改

1. 增加预抬独立 PID 的 XY 增益倍率：默认位置倍率 `[3, 3, 1]`、速度倍率 `[1.5, 1.5, 1]`；只作用于预抬阶段。
2. 增加预抬阶段独立最大倾角参数 `prelift_max_tilt_deg=12`，普通飞行和协同运输使用原参数。
3. `max_lead` 触发后先保持当前参考 `prelift_lead_hold_s=10 s`，期间等待负载间隙增加；没有进展才进入受控降落。目标参考不会继续无限上移。
4. 修复增益缩放原地修改配置数组的问题，避免每个控制周期重复放大后溢出。

## 验证

- 主测试：`110 passed, 1 skipped`。
- MuJoCo 三维闭环：预抬、绳索变紧、接管及后续悬停流程通过；XY 偏差和负载间隙均有回归检查。
