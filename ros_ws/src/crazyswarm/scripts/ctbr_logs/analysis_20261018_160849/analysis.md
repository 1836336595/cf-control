## 新增分项把问题定位到哪里

全部三机协同计算共817×3个输出，`raw_link_force == limited_link_force`，两类限幅标志均为0。因此异常波动已存在于限制器输入，进一步收紧输出滤波不等同于修复闭环。

| --- | ---: | ---: |
| 绳向修正力y | .00423N | .04032N |

后期日志模型中给每机的负载平移y力标准差仅约.0031N。按记录的负载姿态、角速度和期望力矩近似分解，CF4角加速度补偿y标准差约.0203N，与绳向修正y的相关系数约+.816；CF5约+.798。这两个反馈路径的振荡变化在后两架飞机上多为同相；平均力可能相反，正相关不代表每一帧绝对力方向都相同。这是需要重点隔离验证的增长路径。

分解利用 `u_parallel + u_perp = mu_i + m*l*|omega_link|²*q + m*ai + link_force`，把平行和垂直分量合并后再比较，避免把两个会互相抵消的投影分量当成独立净作用。

重建依赖SO(3)姿态误差主分支、目标水平姿态以及异步日志；它是控制器模型内部贡献，不是实测张力，也不能仅凭相关性认定角加速度补偿公式符号错误。主机角速度命令仍可由R=[12,12,6]、D=[.25,.25,.125]重建到约1e-16，姿态误差项继续明显大于角速度阻尼项。

## 倾斜和几何约束仍未解决

相对SO(3)误差反算的pitch均值约20°→17°，并非小角噪声；主分支反算假设相对角度小于90°。绳几何反演也看到相近的悬空倾斜，恢复的是控制器使用的姿态，不是独立物理标定。

1. 车辆位置保持围绕实测接管锚点，随后主要整体平移；拉平负载需要改变三机相对高度/绳向，这两项目标可能相互牵制。
2. 分配器先分配三个任意3D虚拟力，再投影到实际绳向。固定绳向只有三个标量张力，不能即时独立满足六维合力/力矩。外张nullspace偏置只在投影前中性，投影后会出现附加力矩。接管首帧模型内该偏置约产生+1.57mN·m俯仰力矩，期望俯仰力矩约−1.78mN·m；这不是实测绳张力或实际净力矩。
3. 本次有效绳长仍为.689/.699/.664m，没有自动校准提交；接近接管时测距约.718/.704/.685m。宽松30mm准入允许切换，不能证明吊点/质心/绳端位置和绳长模型准确。
4. 姿态环没有恒定偏差补偿，但应先验证可实现分配和构型，再考虑有界积分；直接加大刚度或加I可能继续激励该模态。

## 下一步建议

本轮应优先隔离负载姿态/绳向耦合，而不是继续归因于上一次动捕停更或把限制器错误视为已经解决全部稳定性问题。

第一项单变量候选：将负载 `attitude_bandwidth_hz` 从 `[2.0,2.0,.45]` 改为 `[1.0,1.0,.45]`，阻尼比仍.90；飞机增益、绳向增益、外张偏置和保护阈值保持相同。由KR=J(2πf)²、Kw=2ζJ(2πf)，roll/pitch刚度降至四分之一、速率增益降至一半，并同步降低相关角加速度补偿的响应。它只是原因隔离候选，可能增加静态姿态误差，不能事先称为稳定参数。

先在原Udaan/MuJoCo主机控制器回放中观察接管后60秒，并让初始锚点/倾斜/绳长误差和时序更贴近本次实机；同时加入姿态误差和振荡增长指标。旧仿真最终仅约4.9°pitch而本次仍17°，说明验证模型与实机静态平衡还不一致。

若低带宽仍有约2Hz增长，再分别隔离负载yaw通道、绳向刚度和外张偏置；每次只改一项。针对静态倾斜，应核对质心/真实吊点/飞机绳端锚点，允许参考构型平滑转向水平平衡，并加入明确的间距约束。可考虑非负张力约束分配，优先竖直支撑和roll/pitch力矩、记录不可实现残差，而非假定投影后全部力矩已实现。

下降阶段也应增加基于闭合速度的间距约束/提前退出验证；本次在持续增长振荡下启动下降，保护触发后机间距仍显著缩小，现有“触发后直接从各自当前位置下降”并不能保证避免接近。需要在仿真验证整个退出过程，不能仅延长验证计时或放宽.30m边界。
