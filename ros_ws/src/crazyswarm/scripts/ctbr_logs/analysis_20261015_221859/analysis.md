# 实飞吊运接管振荡与稳定仿真差异

输入：实飞 `multi_ctbr_20261015_221859.csv`，稳定仿真 `final_stable_60/multi_ctbr_20261015_171610.csv` 与其 `input_parameters.yaml`、`summary.json`，当前 ROS/固件/MuJoCo 源码。全程仅做离线分析，没有修改控制器、固件或实飞参数。

复现分析及作图：

```bash
/home/csy/miniconda3/bin/python analyze_oscillation.py
```

输出为 `metrics.json` 和 `handoff_comparison.png`。

## 实飞的异常发生在何时

实飞在控制时间 **49.27365 s** 进入 TAUT_RAMP；5 秒张力渐增至 **54.28 s**。之前独立预抬最后 5 秒较安静，三机横向角速度 RMS 约 0.02–0.04 rad/s。

| 相对接管时间 | 观测 |
| --- | --- |
| 0–2 s | 接管比例从 0 到约 0.32，角速度仍较小，推力变化平滑 |
| 2–3 s | 接管比例约 0.32–0.68，约 4–5 Hz 振荡开始放大；CF5 滚转角速度 RMS 约 0.394 rad/s |
| 3–5 s | 横向角速度指令频繁达到 ±3 rad/s；CF3、CF4、CF5 任一横向指令饱和的采样比例分别约 80.7%、67.9%、83.6% |
| 5 s 以后 | 饱和比例约 89.9%–94.6%，负载已降至接近地面 |

CF3 全段实测横向角速度最大约 6.63 rad/s。负载实测底面间隙从接管时约 0.64 m 降到张力渐增结束时约 0.003 m。这次已经是明显失稳和负载落地，不能只描述为轻微抖动。

三机横向角速度主要谱峰约 3.8–4.9 Hz。这里频谱取 51–56.3 s 的记录，只反映这个短段的主要频率，不能据此断言具体的电机或绳摆固有频率。

实飞角速度指令可由日志完整重建。x/y 轴在接管比例 β 下为：

```text
ω_cmd = clip( -[(1-β)·12 + β·6]·e_R - β·2·ω_mocap, ±3 )
```

三机重建与 CSV 指令的最大误差约 4.4e−16–8.9e−16。这确认主机使用的是预期的姿态增益及角速度反馈增益，没有证据表明节点读取了另一套增益。

`transport_rate_gain` 在这里是把测得的角速度反馈进下一条角速度指令的主机环路增益，不等于机载角速度 PID 的 D 增益。其稳定效果依赖测量滤波、通信时延及机载执行器响应。接管比例增加时该反馈项由零增大，振荡也在这一阶段放大；这是当前指向角速度闭环的强证据，但单次闭环日志不能证明该项是唯一原因。

## 最大的结构差异：机载控制器没有等价建模

当前 `hover_swarm.launch` 设置 `flightmode.stabModeRoll/Pitch/Yaw=0`（RATE），同时设置 `stabilizer.controller=2`（Mellinger）。未发现机型或单机配置覆盖该 controller 选择。

仓库中的固件路径：

- `crazyflie-firmware/src/modules/src/crtp_commander_rpyt.c:179-196`：RATE 输入写到 `attitudeRate.roll/pitch`，`attitude.roll/pitch` 被置为零。
- `controller_mellinger.c:173-180`：位置模式关闭时仍从 attitude roll/pitch 构造期望推力轴，因此此时目标倾角指向水平。
- `controller_mellinger.c:247-287`：仍计算姿态误差，并输出姿态回正项、角速度误差项和角速度误差微分项。该实现未用 roll/pitch 的 `modeVelocity` 分支关闭姿态回正。
- `controller_mellinger.c:302-305`：输出力矩通道限制在 ±32000。

仿真 `simulate_uav/udaan/udaan/models/mujoco/crazyswarm_slung.py:980-1001` 则直接使用：

```text
ω_dot = bandwidth · (ω_command − ω)
torque = I·ω_dot + ω×Iω
```

该模型没有 Mellinger 的姿态回正、指令微分、真实混控以及各电机/力矩输出饱和。

一个可从源码直接验证的差异：倾斜 10°、角速度为零、指令角速度也为零时，仿真角速度环输出零恢复力矩；上述 Mellinger 源码的 roll 姿态回正项约为 −24311 个混控单位。此外，`kd_omega_rp=200`、内环周期约 0.002 s 时，单次 0.32 rad/s 的期望角速度变化，就会在误差微分项产生约 32000 个瞬时输出单位。实飞记录中存在更大的相邻指令变化。这提示微分激励和限幅可能参与了放大，但 CSV 没有机载力矩/电机日志，不能把理论计算写成实测电机饱和。

**限制：**检查时 ROS master 已退出，CSV 也未记录运行固件版本和实时机载 controller 读回。因此可以确认源码/配置与仿真不等价，尚不能仅凭此认定每架飞机正在运行完全相同的已检视固件。应先核实运行控制器、RATE 模式和固件版本。

不能直接把 controller 改成 1 就认定修复：本地 PID 的 pitch 速率通道和 Mellinger 使用不同的 legacy 符号处理，yaw 也有不同目标处理，必须一起验证映射。当前桥接的 pitch/yaw 符号不能未经检查直接沿用到另一控制器。

## 第二项差异：实际推力映射与直接施加牛顿值

在接管前 46.0–49.2 s 的较安静阶段：

- 配置总质量为 0.1838 kg，系统重力约 **1.8025 N**。
- 用该段位置拟合得到系统质心竖直加速度约 −0.0096 m/s²，所需总竖直力约 **1.8007 N**。
- 由三机 `command_thrust_newton × cos(roll) × cos(pitch)` 求和，平均竖直推力指令约 **2.1987 N**，标准差约 0.0044 N。

按配置质量推算，实际维持该运动所需的升力约是指令的 **81.9%**。这说明指令牛顿值到实际升力之间存在明显标定差异或物理参数误差；若质量配置不准确，估计也会相应改变，不能直接把 0.819 当成已经标定的执行器系数。

| 飞机 | 起飞前冻结电压 | 张力渐增段电压范围 | 该段最大 raw 指令 |
| --- | ---: | ---: | ---: |
| CF3 | 3.853 V | 3.341–3.521 V | 60000 |
| CF4 | 3.933 V | 3.431–3.516 V | 59071 |
| CF5 | 3.901 V | 3.399–3.489 V | 59551 |

当前电压缩放起飞前冻结，带载压降未用于飞行中重新标定。压降是推力偏差的合理来源之一，但仅此 CSV 不能排除电机/桨、质量及推力曲线误差。

仿真直接把 `VehicleCommand.thrust` 当作牛顿施加，仅加约 12 ms 的一阶滞后，绕过了 C++ 的 PWM 反解、电压、固件混控和电机输出限制。这些差异会改变保持负载时的推力余量和姿态控制能力。

## 其他未覆盖的因素

- 稳定仿真每 100 Hz 将延迟真值速度/加速度直接写入 `latest_ekf_state`；实际使用 50 Hz 固件 EKF 回传，并经过主机 5 Hz 二阶滤波。收到的数据新鲜，不意味着估计与滤波没有群延迟。
- 稳定仿真使用固定 20 ms 位姿延迟、10 ms 命令延迟及固定调度；实际 ramp 控制间隔中位约 14.28 ms，范围约 5.24–32.05 ms。实际命令到机载执行的延迟没有被 CSV 测量。
- 仿真为负载施加额外旋转阻尼 0.001 N·m·s/rad；按配置箱体惯量，其孤立阻尼时间常数约 27–45 ms。这一阻尼没有由本次实飞辨识。
- 稳定仿真从已建立的平衡收绳构型开始，接管时负载中心约 0.368 m；实飞经过起飞、持续预抬后接管，负载中心约 0.676 m。两者接管初始状态不同。
- 运输姿态增益 `[6,6,3]`、角速度反馈增益 `[2,2,1]` 与稳定仿真快照一致；当前文件相对该快照还有 CF5 绳长 0.681→0.674 m、预抬 XY P 倍率 3→4、D 倍率 1.5→2、收绳容差 0.01→0.015 m 的差异。单靠这几个文件变化不足以解释全部振荡。

## 保护与后续处理顺序

当前 `transport_fault_confirm_s: 20.20` 是 **20.2 秒**。这次接管后只记录约 7.4 秒，掉高与持续角速度饱和的确认时间明显长于失稳发展时间，所以这两项持续故障保护未及时介入。实际距离越界仍为立即触发。

建议先处理执行链一致性，再做参数选择：

1. 核实实际运行固件、controller、RATE 通道语义和符号；确定主机角速度命令对应的真实机载控制环，避免重复姿态控制。
2. 让仿真复现该内环、指令微分及执行器限制，补入 50 Hz EKF 反馈链和采样抖动。保留 `post_handoff_s: 60.0`。
3. 用带载/加载电压标定约束推力映射，避免把未经核对的牛顿指令等同于真实升力。
4. 在该模型上比较较低的 `transport_rate_gain` 与当前值，检查约 4–5 Hz 模态及饱和；在确认模型响应之前，不能把单次日志反算出的“去掉角速度项后的指令”当成已经验证稳定的新闭环。
5. 恢复并验证适合故障发展时间的保护确认时长，再进行后续实飞验证。

本次结论是：既有稳定仿真验证范围不足，特别是遗漏了真实机载内环与推力映射；日志强烈指向角速度反馈接管过程中的闭环失稳。仍需机载读回或同等模型试验区分内环响应、执行器和反馈时延各自的贡献。
