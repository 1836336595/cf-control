# 轻载接管构型与水平目标：几何敏感性估计

本文件只作离线分析。未修改控制器或参数，没有启动 ROS、仿真或实机。输入为 `../multi_ctbr_20261018_211815.csv`，CF3/4/5 每周期时间戳已检查对齐。

复现：

```bash
python crazyswarm/ros_ws/src/crazyswarm/scripts/ctbr_logs/analysis_20261018_211815/analyze_geometry_conflict.py
```

结果输出至同目录 `geometry_conflict.json`。脚本冻结当前几何与飞机质量、独立位置反馈增益，后续 YAML 修改不会改变本次分析的假设。

## 计算方法

以 CSV 的负载中心 `p0`、三机位置 `pv_i` 和控制器输出绳方向 `q_i` 拟合旋转 `R`：

```text
q_i ≈ normalize(p0 + R rho_i - pv_i)
rho_CF3 = [ .04,  .00, .025] m
rho_CF4 = [-.04,  .03, .025] m
rho_CF5 = [-.04, -.03, .025] m
```

保持负载中心及世界绳方向不变，将负载旋转为假定水平、零 yaw 目标 `Rd=I`，三机应随挂点移动：

```text
delta_pv_i = (Rd - R) rho_i
```

固定原先位置保持锚点时，对上述位移产生的位置反馈增量近似为：

```text
delta_F_hold_i = -hold_scale * m_i * Kp_independent_i * delta_pv_i
delta_F_load_i ≈ q_i * (q_i dot delta_F_hold_i)
delta_M_load_world ≈ sum(cross(Rd rho_i, delta_F_load_i))
```

最后一式是在假定拉紧、无质量绳、准静态、原方向保持不变的条件下，将飞机力增量投影到绳方向。它不是实际张力记录，也不是完整闭环预测。当前控制器请求的机体系负载力矩另用 `R @ M_requested_body` 变换到世界系，避免直接比较不同坐标系。

## 限制与坐标假设

- 姿态来自控制器自己的 `q` 和已记录位置反演，反映控制器使用的几何；不是独立的物理姿态测量。NOKOV 刚体偏置或刚体姿态误识别会共同进入这些量，不能用这项反演排除它们。
- 微小拟合残差说明所选记录内部相容，不代表真实吊点、质心或机体端点坐标准确。CSV 多线程采样也可能使其他周期不完全相容。
- 挂点 `rho` 以负载几何中心为原点。本估计与当前模型一样假定满配挂件、标记后的负载质心等于几何中心、尺寸为 `[.08,.06,.05] m`。若轻载质量分布或悬挂硬件使质心偏移，力臂与惯量都需重新标定；23 g 的总质量本身不能保证这些假设。
- 飞机动捕原点被当作绳端点；没有建模实际绳端相对刚体原点的偏移。用户确认量尺端点为负载挂点到飞机动捕原点，但这与实际张力作用点是否一致仍需区分。
- 固定 q 的完整位移保持理想绳长，但真实过程中的 q、张力、速度、飞机姿态和力分配都会变化。估计忽略已有跟踪偏差、速度阻尼、限幅、执行器及接管动态，不能把表格力矩视为“实际剩余力矩”或两个闭环力矩的逐项精确抵消。
- 当前位置保持还经 `transport_blend` 缩放。脚本同时保存 full-blend 潜在增量和按所取样本 blend 缩放后的增量。
- ramp 前 5 秒 CSV 的 `target_x/y/z` 是原先参考向实测锚点的平滑过渡；附加保持实际使用 `position_hold_position=physical_positions`。两种参考不完全相同，不能只用该段 CSV target 解释保持作用。ramp 完成后两者一致。

因此，下一项结构对照应让参考构型缓慢与水平目标一致，例如在 C2 过渡内引入 `(Rd-R_handoff) rho_i`，同时检查实际绳端、绳长可达性和机间距。它需要先在含实测倾斜初态与故障退出的仿真中验证，不能直接把本计算当成实飞修复证明。
