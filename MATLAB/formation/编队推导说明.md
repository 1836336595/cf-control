# 三机编队的 `R_c` 与期望角速度推导

本文统一采用 `simulator/CTBR/codex/v2` 的坐标约定：惯性系 `e3=[0;0;1]` 指向重力，位置 `z` 轴向下；`R` 是机体系到惯性系的旋转矩阵，动力学为

```
m_i * vdot_i = m_i*g*e3 - f_i*R_i*e3
```

定义期望惯性系合力 `A_i`，使得 `f_i*R_i*e3 = -A_i`。于是

```
f_i = -A_i' * R_i * e3,       b3c_i = -A_i / norm(A_i).
```

给定航向参考 `b1d_i = R_d_i*e1`，令

```
P_i = I - b3c_i*b3c_i',       p_i = P_i*b1d_i,
b1c_i = p_i/norm(p_i),        b2c_i = b3c_i x b1c_i,
R_c_i = [b1c_i, b2c_i, b3c_i].
```

当 `norm(A_i)` 或 `norm(p_i)` 接近零时，程序沿用上一时刻的轴；第一帧使用 `e3` 和 `e1` 作为备用方向。

## 1. 位移型编队（几何领航机 + 分布式跟随机）

设固定编队偏移为 `r_i`，邻接权重为 `a_ij`，并令 1 号机为几何领航机。
三架飞机的偏移满足 `sum_i r_i=0`，所以共同参考点 `p_c` 是编队几何中心。

1 号机使用几何控制单机中的绝对位置误差

```
e_x1 = p_1 - (p_c+r_1),    e_v1 = v_1 - pdot_c
```

其期望加速度为

```
u_1 = pddot_c - kx*e_x1 - kv*e_v1 - ki*sat(e_I1)
```

其中 `e_I1` 的积分输入为 `e_v1+c1*e_x1`，因此
`A_1=-m_1*(g*e3-u_1)`。

2、3 号机使用位移型分布式一致性控制律，定义

```
e_ij = (p_i-p_j) - (r_i-r_j)
E_i  = sum_j a_ij*e_ij
V_i  = sum_j a_ij*(v_i-v_j)
u_i  = -kp*E_i - kv*V_i + pddot_c,   i=2,3.
```

和单机几何位置控制的关系 `(f_i/m_i)R_i e3 = g e3-u_i` 给出

```
A_i = -m_i*(g*e3 - pddot_c + kp*E_i + kv*V_i),   i=2,3.
```

因为偏移 `r_i` 为常量，`E_dot_i=V_i`。在仿真中用当前控制输入近似加速度，`V_dot_i = sum_j a_ij*(u_i-u_j)`，故

```
A_dot_i = m_i*(pjerk_c - kp*V_i - kv*V_dot_i).
```

注意：PDF 中的纯位移型控制只约束相对位置和相对速度，不能决定编队
质心的绝对平移。代码对 2、3 号机默认加入 `commonAcceleration` 前馈：

```
u_i = -kp*E_i - kv*V_i + a_c
A_i = -m_i*(g*e3 - a_c + kp*E_i + kv*V_i)
A_dot_i = m_i*(jerk_c - kp*V_i - kv*V_dot_i)
```

其中 `a_c` 和 `jerk_c` 分别是 8 字参考轨迹的共同加速度和 jerk；将该选项
关闭后，2、3 号机退化为 PDF 式纯相对位移控制。若将类型改为
`displacement_pure`，则三架飞机都使用纯相对位移控制。

## 2. 领导-跟随编队（虚拟中心领导者、三机全分布式）

这里的领导者不是三架飞机中的某一架，而是三架飞机的几何中心虚拟点
`p_c(t)`。固定偏移满足 `sum_i r_i=0`，三架飞机的目标位置为 `p_c+r_i`。
定义

```
e_i   = p_i - p_c - r_i,       eta_i = v_i - pdot_c,
E_i   = sum_j a_ij*e_ij,        V_i   = sum_j a_ij*(v_i-v_j),
u_i   = pddot_c - kf*E_i - kvf*V_i - kbl*b_i*e_i - kvl*b_i*eta_i.
```

这里 `b_i` 是领导-跟随误差的标量增益（代码中统一为 `bl_i`）。本实现取
`bl=[1;1;1]`，三架飞机都直接获得虚拟中心参考，同时使用通信图上的相对
误差；不存在物理领航飞机的单机位置控制器。因此

```
A_i = -m_i*(g*e3 - pddot_c + kf*E_i + kvf*V_i
            + kbl*bl_i*e_i + kvl*bl_i*eta_i).
```

由于 `E_dot_i=V_i`、`e_dot_i=eta_i`、`eta_dot_i=u_i-pddot_c`，以及 `V_dot_i=sum_j a_ij*(u_i-u_j)`，有

```
A_dot_i = -m_i*(-pjerk_c + kf*V_i + kvf*V_dot_i
                 + kbl*bl_i*eta_i + kvl*bl_i*(u_i-pddot_c)).
```

代码中的 `pjerk_c` 由 8 字虚拟中心轨迹直接给出。

“不使用几何控制”仅指不使用某一架飞机的单机平动位置控制器。三架四旋翼
仍必须把分布式控制律产生的 `u_i` 转换成推力方向和姿态，因此统一使用
`A_i -> R_c,i -> Omega_c,i` 的几何姿态映射。

## 3. 期望角速度

对上面的 `R_c=[b1c,b2c,b3c]` 求导：

```
b3c_dot = -(I-b3c*b3c')*A_dot/norm(A),
p_dot   = -(b3c_dot*b3c' + b3c*b3c_dot')*b1d + P*b1d_dot,
b1c_dot = (I-b1c*b1c')*p_dot/norm(p),
b2c_dot = b3c_dot x b1c + b3c x b1c_dot,
R_c_dot = [b1c_dot,b2c_dot,b3c_dot].
```

最终

```
hat(Omega_c) = R_c' * R_c_dot,
Omega_c = vee(0.5*(R_c'*R_c_dot - R_c_dot'*R_c)).
```

三机 CTBR 外环使用 V2 的姿态误差和角速度命令：

```
e_R = 0.5*vee(R_c'*R - R'*R_c)
Omega_cmd = R'*R_c*Omega_c - kR.*e_R.
```

若使用离散模式，则将解析式替换为
`Omega_c(k)=vee(log(R_c(k-1)'*R_c(k)))/dt`；代码通过 `cfg.omegaCMethod` 支持两种模式。
